## Important Git commands for daily use

| Command | Purpose |
|---|---|
| `git clone URL` | Download a GitHub repository |
| `git pull` | Get the latest changes |
| `git fetch` | Download updates without merging |
| `git branch` | View branches |
| `git branch new-branch` | Create a new branch |
| `git checkout main` | Switch to the `main` branch |
| `git switch -c feature` | Create and switch to a branch |
| `git merge feature` | Merge a branch |
| `git remote -v` | View connected GitHub repository |
| `git stash` | Temporarily save uncommitted changes |
| `git stash pop` | Restore stashed changes |
